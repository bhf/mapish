Off-Heap Mapish

A high-performance, single-threaded, off-heap hash map implementation using Java's Foreign Function & Memory (FFM) API.

View on GitHub View Benchmarks

Installation

Mapish is published to GitHub Packages. Add the following to your build.gradle.kts:

repositories { 
    mavenCentral() 
    maven { 
        url = uri("https://maven.pkg.github.com/bhf/mapish") 
        credentials { 
            username = System.getenv("GITHUB_ACTOR") 
            password = System.getenv("GITHUB_TOKEN") 
        } 
    } 
} 

dependencies { 
    implementation("com.bhf.mapish:off-heap-map:1.0-SNAPSHOT") 
}

* Note: You will need a GitHub Personal Access Token (PAT) with the read:packages scope to consume the dependency.

Why Off-Heap?

Zero GC Pressure

Bypasses the Java Garbage Collector for table nodes. Memory is stored entirely natively via Arena.ofConfined() or ofAuto().

Cache Locality

Uses Open Addressing with Linear Probing in a single, contiguous MemorySegment. Say goodbye to scattered LinkedList pointers.

Blazing Fast

Direct bit-comparisons using MemorySegment.mismatch() completely eliminate expensive string or object deserialization on lookups.
